# Screenshots

Add terminal screenshots here before publishing the repository. Suggested
files:

| File | Capture |
| --- | --- |
| `main-menu.png` | Welcome banner and main menu |
| `add-expense.png` | Completed expense form and confirmation |
| `monthly-summary.png` | Totals, budget progress bar and insights |
| `reports.png` | Category table and monthly overview |
| `budget-warning.png` | An over-budget alert |

Tips:

1. Run `python3 main.py --sample` first so the screens have realistic data.
2. Use a terminal about 90-100 columns wide.
3. On macOS press `Cmd+Shift+4`, on Windows use `Win+Shift+S`.
4. Keep images reasonably small (under ~500 KB) so the repository stays light.
5. Reference them from the main README, for example:

   ```markdown
   ![Monthly summary](docs/screenshots/monthly-summary.png)
   ```

Never screenshot real personal financial data.
